# Third-party tools

Installed from their source, not copied here, so they keep receiving updates.

| What | Source | Install |
|---|---|---|
| `caveman-learn`, `caveman-review`, `caveman-stats` skills | [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) | `npx skills add JuliusBrussee/caveman` |
| `find-skills` skill | [vercel-labs/skills](https://github.com/vercel-labs/skills) | `npx skills add vercel-labs/skills` |
| `security-audit` skill (per project) | [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) | `npx skills add cloudflare/security-audit-skill` in the project |
| `feature-dev` plugin | `claude-plugins-official` marketplace | `/plugin install feature-dev@claude-plugins-official` |
| RTK (token-saving CLI proxy + hook) | [rtk-ai.app](https://www.rtk-ai.app/) | `brew install rtk`, then reference `RTK.md` from `~/.claude/CLAUDE.md` |
